## v1 Requirements

### Hero

- [ ] **HERO-01**: Người dùng thấy ảnh nền Valorant fullscreen với overlay màu tối khi vào trang
- [ ] **HERO-02**: Logo + tên KYTOO.GG nổi bật trên hero, nhận diện thương hiệu ngay lập tức
- [ ] **HERO-03**: Tagline ngắn 1 dòng mô tả thương hiệu (ví dụ: "Merch Valorant chính hiệu")
- [ ] **HERO-04**: Nút CTA "Mua ngay" / "Xem Shop Shopee" dẫn link đến Shopee shop KYTOO

### Sản phẩm

- [ ] **PROD-01**: Grid card hiển thị ảnh, tên, giá từng sản phẩm — dùng ảnh từ `images/`
- [ ] **PROD-02**: Nút "Mua trên Shopee" riêng từng sản phẩm, link thẳng đến listing Shopee tương ứng
- [ ] **PROD-03**: Modal/popup chi tiết sản phẩm khi click card — không rời trang

### About

- [ ] **ABOUT-01**: Section giới thiệu thương hiệu KYTOO.GG (1-2 đoạn văn)
- [ ] **ABOUT-02**: UVP rõ ràng — lý do chọn KYTOO (chất lượng, thiết kế Valorant-themed, độc đáo)
- [ ] **ABOUT-03**: Số liệu uy tín hiển thị (số đơn đã bán, rating/review nếu có)

### Liên hệ

- [ ] **CONTACT-01**: Hiển thị icon/link Zalo và Facebook để khách liên hệ nhanh

### Technical

- [ ] **TECH-01**: Responsive mobile-first — hiển thị tốt trên điện thoại
- [ ] **TECH-02**: Single-file `index.html` + Tailwind CSS CDN + Vanilla JS — không build step
- [ ] **TECH-03**: Deploy tĩnh — tương thích GitHub Pages / Netlify

## v2 Requirements (Deferred)

- Form liên hệ Formspree (email về hộp thư) — sau khi v1 live và có traffic
- Badge sản phẩm (mới, hot, giảm giá) — khi có chiến dịch marketing
- Google Analytics — phase riêng sau launch
- SEO / Open Graph — phase riêng sau launch
- Lazy loading ảnh — tối ưu hoá sau khi content ổn định

## Out of Scope

- Giỏ hàng / thanh toán trực tiếp — Shopee làm thay, không cần build
- User account / login — không có nhu cầu cho landing page
- CMS / admin panel — cập nhật thủ công HTML là đủ cho quy mô này
- Build system (Vite, Webpack) — single-file không cần bundler
- Đa ngôn ngữ — chỉ tiếng Việt, thị trường VN
