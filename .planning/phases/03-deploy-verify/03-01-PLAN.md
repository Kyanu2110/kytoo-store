| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | User-provided Shopee URLs | mitigate | Claude must verify each URL starts with `https://shopee.vn/` before writing to index.html; reject any URL not matching this pattern |
| T-03-02 | Information Disclosure | Public GitHub repo | accept | Single-file site, no API keys, no secrets, no user data; public visibility is intentional for free hosting |
| T-03-03 | Spoofing | External links (target="_blank") | mitigate | All external `<a>` tags already have `rel="noopener noreferrer"` — verify this is present on all Shopee links written in Task 4 |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | Phase 3 has zero package installs — static site deploy only, no dependency changes |
</threat_model>
