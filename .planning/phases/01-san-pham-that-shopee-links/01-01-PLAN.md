<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer → index.html | Only developer edits the file; no user input goes into HTML at runtime |
| index.html → external Shopee URLs | href values redirect user browser to Shopee; must be hardcoded strings only |
| img src → /images/ path | Image loading from local /images/ path; onerror runs inline JS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | href values on Shopee CTAs | mitigate | All href values are hardcoded string literals set at plan-time by executor from user-provided URLs; no dynamic construction or user-controlled input; executor must verify each href starts with `https://shopee.vn/` before committing |
| T-01-02 | Spoofing | onerror inline handler on img tags | mitigate | onerror value is a hardcoded literal string `this.style.display='none'; this.parentElement.style.background='linear-gradient(135deg,#0e1a28,#1a2a3e)'` — no eval, no external URL, no function call; executor must not deviate from this exact pattern |
| T-01-03 | Info Disclosure | img src paths | mitigate | All img src values use relative `/images/[filename]` paths only (D-01); no external URLs, no user-controlled filenames at runtime; executor must verify all img src values follow `/images/` prefix |
| T-01-04 | Tampering | agents[] JS array shopeeLink field | mitigate | shopeeLink values are hardcoded at build time from user-provided URLs; switchAgent() function reads these values and writes to href — executor must ensure no template literals with dynamic input are used; value must be a quoted string literal |
| T-01-05 | Elevation of Privilege | External scripts (Tailwind CDN, Lucide CDN) | accept | CDN dependencies are pre-existing and out of scope for this phase; risk accepted as these were present before Phase 1 |
</threat_model>
